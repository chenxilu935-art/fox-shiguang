## 界面与使用

[左右书桌](images/stage4-desk-wide.png) · [入库预览](images/stage4-publish-preview.png) · [窄屏](images/stage4-desk-narrow.png)

默认空白有序文档，文字与引用可自由编辑、移动、删除。模板仅插入可修改的初始 Markdown。预览后一次确认，默认写入 `20-Knowledge/`；`shiguangSourceId` 识别来源，`shiguangTopics` 保持原结构。新草稿保存在插件私有 `desk-drafts.json`，不改旧固定字段草稿。保存失败阻止通常的关闭/切换，原生视图关闭失败时保留会话恢复副本。

交互借鉴 [VibeDesign 连续性](https://vibedesign.tips/zh/015-ui-continuity/) 与 [轻量反馈](https://vibedesign.tips/zh/016-toast-or-notification/)：真实卡片几何展开/反向返回、短暂纸条滑入、保留和摘录撤销。先完成操作，再尝试动画；禁用或失败不影响数据。

## 限制与清理

- 原生链接随改名更新需 Obsidian 启用更新内部链接；卡片查找使用稳定 ID。重启测试使用该原生设置。
- 等待「草稿已保存」后退出。强制结束进程、磁盘故障且尚未确认保存时，不能保证最后输入恢复；会话恢复不替代持久保存。
- 本轮实际媒体覆盖本地图片；音视频编码和所有第三方 Markdown 处理器组合未逐项测试。
- 没有实现历史固定字段草稿自动迁移、AI 服务、跨插件 API 或复杂模板管理。
